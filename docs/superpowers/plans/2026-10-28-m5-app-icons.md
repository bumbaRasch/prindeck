# M5 App and Tray Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default Tauri scaffold icons and the four tray state icons with the project's brand images from `images/`.

**Architecture:** One maintainer script derives the tray set (background → alpha, recolor per state, 32×32) from `images/dark background.png`; the official `tauri icon` CLI regenerates the whole application icon set from `images/logo.png`. No Rust or TS code changes.

**Tech Stack:** Python 3 + Pillow (system interpreter, maintainer-only), `@tauri-apps/cli` `tauri icon` subcommand.

**Spec:** `docs/superpowers/specs/2026-10-28-app-icons-design.md` — the plan argues from the spec; executors read both.

## Global Constraints

- Commit prefix `M5:`. Script is English, no comments, ≤ 200 lines.
- State colors exact: idle `#00D9C8`, working `#4b8ef7`, error `#e5534b`, offline `#9aa2ad` (author-confirmed 28.10.2026).
- Tray outputs: `src-tauri/icons/tray-{idle,working,error,offline}.png`, 32×32 RGBA, transparent outside the glyph, the knocked-out dot stays transparent.
- `src-tauri/src/tray/icons.rs` and `src-tauri/tauri.conf.json` are not modified.
- ImageMagick is a system dependency (`sudo apt install imagemagick`), never a project dependency; intermediates go to `/tmp/opencode/prindeck-icons/`.
- Ritual green before each commit: `cargo test --workspace`, `cargo check --workspace --all-targets`, `cargo clippy --workspace --all-targets -- -D warnings`, `npm run typecheck`, `npm run build`, `npm run check:code-language`, `npm run check:line-count`.
- Do not contact the printer; the offline tray check uses an unroutable host only.

## Review Focus

1. **Fuzz too tight/loose in background removal** → charcoal halo or eaten glyph at 32×32. Pinned by Task 1 Step 4 pixel assertions (corner alpha 0, glyph pixel exact state color).
2. **The knocked-out dot gets filled** → state icon loses its dot. Pinned by Task 1 Step 4 (dot pixel alpha 0).
3. **Opaque source into `tauri icon`** → command refuses or bakes wrong corners. Pinned by Task 1 Step 3 (command output check + `icon.png` visual inspection).
4. **RGB instead of RGBA output** → black square in the tray. Pinned by Task 1 Step 4 (`%A` is `True`).
5. **State colors swapped between files** → wrong meaning at a glance. Pinned by Task 1 Step 4 (per-file color assertion under the exact state→file name mapping).

### Task 1: Generate the icon sets

**Files:**
- Create: `scripts/make-icons.py`
- Modify (generated binaries): `src-tauri/icons/` — the `tauri icon` output set and `tray-{idle,working,error,offline}.png`
- Add to git: `images/` (four source PNGs, ~1.1 MB each)

**Interfaces:**
- Produces: `python3 scripts/make-icons.py` — idempotent regeneration of the four tray PNGs from `images/dark background.png`; writes only `src-tauri/icons/tray-*.png`.

- [x] **Step 1: Verify Pillow** — `python3 -c "import PIL"` (present as system Pillow 12.1.1; maintainer call — ImageMagick would need a sudo install, see spec).

- [x] **Step 2: Write `scripts/make-icons.py`** and run it. Algorithm: open `images/dark background.png` as RGBA; every pixel within Euclidean RGB distance ≤ 53 (≈ the 12 % fuzz) of the background `#1E2126` becomes fully transparent; resize to 32×32 (LANCZOS); for each state set RGB of every non-transparent pixel to the state color, keep alpha; save `src-tauri/icons/tray-<state>.png`. The script asserts on its own output: 32×32, RGBA, corner alpha 0, glyph coverage > 15 % of pixels, at least one fully transparent pixel strictly inside the glyph bounding box (the knocked-out dot).

- [x] **Step 3: Regenerate the app icon set** — `npm run tauri icon images/logo.png`; expected: it reports generated files into `src-tauri/icons/` without touching `tray-*.png`; if the CLI warns about the opaque source, proceed (full-bleed tile is intended) — only an outright error stops this step.

- [x] **Step 4: Mechanical verification** — the script's own assertions (Step 2) plus: each output re-opened and re-checked (`size == (32, 32)`, `mode == "RGBA"`, corner alpha 0, glyph pixel RGB equals the file's state color, dot pixel alpha 0). Then the full ritual.

- [x] **Step 5: Commit** — `git add images/ scripts/make-icons.sh src-tauri/icons && git commit -m "M5: brand application and tray icons"`
