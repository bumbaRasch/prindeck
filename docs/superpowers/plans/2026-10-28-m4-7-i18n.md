# M4.7 UI Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ten-language UI before publication: system-locale detection with English fallback, typed catalogs on native `Intl`, all user-visible wording moved from Rust to the frontend, Arabic RTL.

**Architecture:** Backend first emits structured kinds instead of worded strings (print/config/startup/alerts, tray labels via IPC), then a zero-dependency i18n runtime (`ui/src/i18n/`) with per-locale catalogs (`ui/src/locales/`), then the screen sweeps consume both. Catalogs are TS modules typed against the `en` catalog — key parity is a type error, placeholder/plural correctness is a new mechanical check script.

**Tech Stack:** Tauri 2 (Rust), vanilla TypeScript strict, native `Intl` (`PluralRules`, `RelativeTimeFormat`, `NumberFormat`, `DateTimeFormat`), official `@tauri-apps/plugin-notification` JS binding.

**Spec:** `docs/superpowers/specs/2026-10-28-i18n-design.md` — the plan argues from the spec; executors read both.

## Global Constraints

- Commit prefix `M4.7:`. All code English, no comments in code. All docs English.
- No new Rust crates. Exactly one new npm package: `@tauri-apps/plugin-notification`.
- Locale tags fixed: `en, ru, uk, de, fr, es, pt-BR, zh-CN, ja, ar`; catalog files `ui/src/locales/{en,ru,uk,de,fr,es,pt_br,zh_cn,ja,ar}.ts` (underscores on disk).
- Kind strings fixed (serde output, exact): print `copies-range|sides-unknown|job-outside-queue|cups-missing|queue-missing|send-failed|queue-failed|cancel-failed` (kebab-case); alerts `toner-low|drum-low|silent|back-online`; scan errors `transport|busy|invalid|device|storage|canceled` (existing camelCase serde of `ScanErrorKind`).
- Config fields (camelCase): `host|pollSeconds|scanDir|notifyTonerPercent|notifyDrumPercent|tonerYieldPages|cupsQueue`; field error kinds: `required|format|range`; startup kinds: `loadFailed|invalid|fallback`.
- No source file over 200 lines; over-limit locale catalogs go into `scripts/line-count-baseline.txt` (existing mechanism of `scripts/check-line-count.sh`).
- Pre-commit ritual green for every commit: `cargo test --workspace`, `cargo check --workspace --all-targets`, `cargo clippy --workspace --all-targets -- -D warnings`, `npm run typecheck`, `npm run build`, `npm run check:code-language`, `npm run check:line-count`; from Task 11 additionally `npm run check:i18n`.
- Do not contact the printer. `PRINDECK_LOCALE` is the development locale override (env var, read by the backend, honoured by the frontend).
- Interim states are accepted inside the milestone: backend tasks land kind payloads before the matching screen sweep words them (Tasks 7–10); the tray shows English until the frontend pushes labels.

## Review Focus

1. **Plural boundaries** (ru `1/21 страница`, `22 страницы`, `5 страниц`; ar `0/1/2/3/11/100` six forms; zh/ja no plurals) — wrong form shown. Pinned by the plural-coverage probe in `scripts/check-i18n.mjs` (Task 11, Steps 1–3).
2. **Placeholder drift in a draft** (a locale drops or renames `{n}`) — broken interpolation. Pinned by placeholder-parity in `check-i18n.mjs` (Task 11, Steps 1–3).
3. **Edge locale tags** (`zh-TW`, `pt-PT`, `it-IT`, lowercase `pt-br`) — wrong match or crash. Pinned by normalization + probes in Task 5, Step 4.
4. **RTL layout in `ar`** — clipping/overlap at 640×480 and maximized, both themes. Pinned by the visual-check pass in Task 13.
5. **Rejected invoke promises carry objects, not strings** (print/config kinds) — string coercion shows `[object Object]`. Pinned by typed rejection handling in Task 9 Step 3 and Task 10 Step 4.
